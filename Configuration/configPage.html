LyricFin: Get Timed Lyrics

Fetches timed LRC lyrics from LRCLIB. The scheduled task only fills tracks that are missing lyrics.

Scheduled runs ignore titles marked (Instrumental) / [Instrumental]. Force fetch clears any existing lyrics on those tracks instead of looking them up.

Matching

Comma-separated markers stripped from track titles before lookup (same as MusicFin), e.g. 🅴 or [Explicit].

Censoring

Mask swear words when lyrics are saved. Already-saved lyrics need Force refresh to re-censor.
One word per line. Clear the box and Save to restore the built-in list.
Advanced
Concurrent tracks (LRCLIB prefers slow/polite clients). 0 or 1 recommended. Max 4.

Force refresh

Overwrites existing lyrics. Watch Dashboard --> Scheduled Tasks --> LyricFin: Get Timed Lyrics.

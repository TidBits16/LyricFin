LyricFin: Get Timed Lyrics

Fetches timed LRC lyrics from LRCLIB. The scheduled task only fills tracks that are missing lyrics. Use the button below to queue a force-refresh (runs under Scheduled Tasks so it will not time out in the browser).

Scheduled runs ignore titles marked (Instrumental) / [Instrumental]. Force fetch clears any existing lyrics on those tracks instead of looking them up.

Matching

Comma-separated markers stripped from track titles before lookup (same as MusicFin), e.g. 🅴 or [Explicit].

Fetch

Queues LyricFin: Fetch All Lyrics under Dashboard --> Scheduled Tasks. Overwrites when timed LRC is found.
Advanced
Concurrent tracks (LRCLIB prefers slow/polite clients). 0 or 1 recommended. Max 4.
